Privacy Policy

Effective date: 10.02.2026

This Privacy Policy explains how P2P File Transfer App ("the App", "we", "us", or "our") handles information when you use the App.

The App is built with privacy and simplicity in mind. We do not collect, store, analyze, or sell personal data.

1. Information We Do Not Collect

We do not collect or have access to:

  • Transferred files or their contents
  • File names, sizes, or hashes
  • User identities or contact lists
  • IP address histories linked to users
  • Location data

All file transfers occur directly between devices using peer-to-peer connections.

2. Local-Only Processing

All files remain on the users’ devices.

The App does not upload, store, cache, or back up files on any servers. Once a transfer is completed, no copy is retained by us.

3. Peer-to-Peer Connections

The App uses peer-to-peer technology to establish direct connections between devices for file transfer.

Whenever possible, data flows directly between peers without passing through any server.

4. Signaling Server

A signaling server is used solely to exchange technical connection information required to establish peer-to-peer connections (e.g. session identifiers and network negotiation data).

The signaling server:

  • Does not process or relay file contents
  • Does not store transferred files
  • Does not maintain persistent user profiles

5. Logs and Analytics

The App does not use analytics, tracking tools, advertising SDKs, or third-party data collection services.

We do not track user behavior or usage patterns.

Minimal technical logs may be generated temporarily on the server to ensure basic operation and stability. Such logs are not linked to individual users and are retained only as long as necessary for troubleshooting.

6. Third-Party Services

The App does not integrate third-party analytics, advertising, or marketing services.

Network infrastructure providers may process encrypted network traffic solely for data transmission purposes.

7. Children’s Privacy

The App is not intended for use by children under the age of 13. We do not knowingly collect personal data from children.

8. Data Security

We apply reasonable technical measures to protect the App’s infrastructure and signaling services.

However, no method of electronic communication can be guaranteed to be completely secure.

9. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will become effective when published.

10. Contact

If you have questions about this Privacy Policy, you may contact us inside the App using the “Contact Developer” option.
